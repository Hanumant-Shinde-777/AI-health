=== STEP 4: OTP SERVICE ===

FILE: services/otpService.js

  Storage:
  - Use in-memory Map for local dev
  - Key: email address
  - Value: { otp, expiresAt, attempts }

  generateOtp(email):
  - Generate random 6-digit number
  - Store in Map with:
      expiresAt = Date.now() + OTP_EXPIRY_MS
      attempts  = 0
  - Console.log OTP in terminal (local dev only)
  - Return OTP string

  verifyOtp(email, inputOtp):
  - Check if record exists → else "OTP not found. Resend."
  - Check if expired → delete record → "OTP expired. Resend."
  - Check attempts >= 3 → delete record → "Too many attempts."
  - Check OTP match → if no: increment attempts → "Invalid OTP."
  - If match → delete record → return success: true

=== STEP 6: AUTH ROUTES ===

FILE: routes/authRoutes.js

  --- ROUTE 1: POST /api/auth/login ---

  Request body: { loginMethod, email, password }

  Logic:
  if loginMethod === 'mobile':
    → return 400: "Mobile login not available yet."
    → DO NOT trigger any OTP or email logic

  if loginMethod === 'email':
    1. Validate email + password present
    2. Find user by email in DB
       → if not found: 404 "User not found."
    3. Compare password using bcrypt.compare()
       → if mismatch: 401 "Invalid password."
    4. IF password valid:
       → generateOtp(email)
       → sendOtpEmail(email, otp, user.name)
       → return 200: { 
           success: true, 
           message: "OTP sent to your email.",
           previewUrl   ← remove in production
         }

  --- ROUTE 2: POST /api/auth/verify-otp ---

  Request body: { email, otp }

  Logic:
  1. Validate email + otp present
  2. Call verifyOtp(email, otp)
  3. If failed → return 400 with verifyOtp message
  4. If success:
     → Find user by email
     → Sign JWT:
         payload: { userId: user._id, email: user.email }
         secret:  JWT_SECRET from .env
         expiry:  '7d'
     → return 200: {
         success: true,
         message: "Login successful.",
         token,
         user: { id, name, email }
       }
